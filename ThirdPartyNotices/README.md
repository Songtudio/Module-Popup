# Third-party assets

## Liberation Sans

Unity's default TextMesh Pro Liberation Sans resources are included for the
generic popup prefabs. The font license is included in `LiberationSans-OFL.txt`.
Unity serialized GUIDs were changed for isolation.

## TextMesh Pro shaders

`Runtime/Defaults/Shaders` contains the shader/include files from the
project's imported TextMesh Pro resources. The shader's display name was given
the `Song/Popup/` prefix to avoid a name collision with host assets.
Unity's uGUI/TextMesh Pro license notice is included in `Unity-Companion-LICENSE.md`.

## Project assets

Popup code and prefab structures originate from CrawlStars. The generic prefabs
use solid colors and contain no CrawlStars-specific font or image assets.
This extraction does not assign a new license to the project's original work.
